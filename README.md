# Cloud-Native Application Platform

A hands-on DevOps and Kubernetes learning project for building and operating a small job application tracking system.

## Project Goal

Build a simple application for tracking job applications and use it to learn the workflow from application development to containerization and Kubernetes deployment.

## Core Features

The application will allow users to:

- Add a job application
- View a single application
- View a list of applications
- Update an application
- Delete an application
- Track application status

Each application will eventually contain information such as:

- Company
- Role
- Application date
- Status
- Notes
- Created and updated timestamps

## Learning Goals

This project will be used to practice:

- Python and FastAPI
- REST APIs
- Automated testing
- PostgreSQL
- Database migrations
- Redis caching and fallback
- Docker
- Docker Compose
- Kubernetes
- Persistent storage
- Health probes and resource management
- Helm
- HTTPS and TLS
- Kubernetes security and NetworkPolicy
- Horizontal Pod Autoscaling
- Troubleshooting and failure recovery
- Git and technical documentation

## Project Scope

This is a local learning lab.

The first version will:

- Run on a local development machine
- Use synthetic or test data
- Not include user authentication
- Not provide production-grade database backup
- Not provide production-grade high availability
